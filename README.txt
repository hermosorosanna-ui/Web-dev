IMPORTANT: IMAGE REPLACEMENT
Every visible image is already assigned a fixed image frame. To replace a placeholder, keep the same filename and overwrite the SVG with your JPG/PNG/WebP, OR update the src in index.php.
The CSS uses width/height plus object-fit: cover inside fixed frames, so the surrounding layout remains the same.
